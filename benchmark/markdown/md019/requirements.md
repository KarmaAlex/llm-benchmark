# Product Requirements — Notification Preferences

- REQ-1: Users can opt out of marketing emails.
- REQ-2: Users can opt out of SMS notifications.
- REQ-3: Users can set a quiet-hours window during which no push
  notifications are sent.
- REQ-4: Admins can view an audit log of a user's notification preference
  changes.
- REQ-5: Users can export their notification preference history as CSV.
